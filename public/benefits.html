Benefits

Pay frontier prices only for frontier questions.

For developers building AI-native apps over an API (see how to integrate). Keep your Anthropic, OpenAI or Gemini SDK and change one base URL. DSI Axon, the blind router, sends each request to the cheapest provider that is good enough for it: an open model on the network for everyday requests, a frontier model for the hard ones.

133× cheaper

A community node on Decentralised.si answers a request for 1/133 of what a flagship model (Claude Fable 5.1 or GPT-6 Astra) charges, at list prices.

87% lower bill

than sending everything to Claude Opus 5.5, when 70% of requests are easy, 20% medium and 10% hard: $2,123 instead of $16,000 for a million requests (set your own mix below).

$0 fee

for routing when you bring your own vendor keys. The network's open models are billed at their listed cost, with no markup.

Integrate in minutes, save from the first request

No new SDK and no rewrite. Your app keeps calling the Anthropic, OpenAI or Gemini API it already uses, through one endpoint that reaches every vendor and the open network.

  1. Get a key. Sign in to the console and create an API key (ds_live_…).
  2. Connect your vendor keys (optional). In Console → Providers, add your Anthropic, OpenAI or Gemini keys. They are stored encrypted, used only to call that vendor for you, and carry no routing fee. This is how hard requests reach frontier models.
  3. Change one line: the base URL.
  4. Turn on routing. By default you get exactly the model you ask for. To save, send X-Decentralise-Mode: optimise (or use model: "auto"), or set optimise once as your account's default in the console. Your code can keep its usual model name: when the router answers with another model, the response says so.
from anthropic import Anthropic

client = Anthropic(
    api_key="ds_live_...",                              # your Decentralised.si key
    base_url="https://api.decentralised.si/anthropic",  # the only change
)

# Your code stays the same. Add a header to let the router find a cheaper
# model that is good enough, or leave it out to get exactly the model you name.
msg = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Summarise this support ticket: ..."}],
    extra_headers={"X-Decentralise-Mode": "optimise", "X-Decentralise-Reasoning": "1"},
)
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.DSI_API_KEY,
  baseURL: "https://api.decentralised.si/openai/v1",   // the only change
});

// Everyday request: the cheapest model that clears the bar.
const quick = await client.chat.completions.create(
  { model: "auto", messages: [{ role: "user", content: "Classify this email: ..." }] },
  { headers: { "X-Decentralise-Mode": "cheapest", "X-Decentralise-Reasoning": "0" } },
);

// Hard request: frontier-grade reasoning, with a quality floor.
const deep = await client.chat.completions.create(
  { model: "auto", messages: [{ role: "user", content: "Find the risks in this contract: ..." }] },
  { headers: { "X-Decentralise-Mode": "quality", "X-Decentralise-Reasoning": "3", "X-Decentralise-Min-Quality": "0.9" } },
);

Choose the reasoning level per request

Send a hint and the router sets its quality target to match. It never reads your prompt to decide.

X-Decentralise-ReasoningUse it forQuality targetTypically answered by
0 · recalllookup, rewriting, classification, extraction0.68small open models, community nodes
1 · generaleveryday Q&A, summaries, code help0.80open models such as Llama 3.3 70B
2 · reasoningmulti-step analysis, agents, planning0.87large open or mid-tier frontier models
3 · frontierresearch, hard reasoning, high-stakes answers0.93the strongest model you have connected (your vendor key)

Without a hint, the router estimates difficulty from the request's shape (size, tools, turns, reasoning settings). Combine the hint with a mode: cheapest, fastest, optimise (best value), quality, private (providers that don't train on or keep your data), decentralised_only, or passthrough (exactly the model you name). Hard limits: X-Decentralise-Min-Quality, X-Decentralise-Max-Cost, X-Decentralise-Max-Latency-Ms. See the API docs. On the open network, reasoning levels 2 and 3 are reserved for accounts that stake PAI; with your own vendor keys, frontier models are used directly.

More connectivity from the same integration

One key, every provider. Anthropic, OpenAI and Gemini (with your keys), open models on Cloudflare Workers AI, and community and specialist nodes on the network, behind one endpoint and one bill.
Automatic failover. If a provider is down or rate-limits you, the request goes to the next suitable one (x-decentralise-failovers says how often). An answer cut off mid-stream continues on another provider instead of failing.
Any protocol, any model. Call a Claude model through the OpenAI SDK, or a Gemini model through the Anthropic SDK: requests and tool calls are translated both ways, streaming included.
Know every answer's cost. Each response names the model and provider that answered and its estimated cost, and carries a receipt you can look up in the console.

Where the savings come from, and their limits

What makes it cheaper

  • Most requests in real apps are routine: summaries, extraction, classification, short answers. They don't need a flagship model.
  • Open models on the network cost a fraction of flagship prices, and community nodes run on hardware members already own.
  • Routing is per request, so hard questions still reach the strongest model you have access to.
  • With your own keys, the router adds no fee to vendor prices.

What to keep in mind

  • Open and small models are not frontier models. The router sets a quality floor per request, but check results for your own use case.
  • Community nodes run on members' machines, so speed and capacity vary with who is online.
  • Vendors offer batch (50% off) and caching discounts that this table leaves out on both sides.
  • Buying network credit is not open yet. Today you can bring your own vendor keys (no routing fee), or run a node for free network chat.

More than price

Privacy by design

  • The router chooses providers from a request's structure and your hints, never by reading your prompt.
  • Network nodes never receive your account identity, and conversations are spread across providers.
  • Usage records hold token counts and costs, not your text. Chat history stays in your browser.
  • Private mode sends requests only to providers that don't train on or keep your data. DSI Synapse can pseudonymise details on your device first.

A node or vendor still sees the text it answers. Privacy policy

Open, with no lock-in

  • Drop-in Anthropic, OpenAI and Gemini APIs, plus MCP: keep your SDK and change the base URL.
  • Your own vendor keys work alongside the network, and you can switch back at any time.
  • The source code is public: DSI Axon, DSI Synapse and this website and app.
  • Open-weight models on the network, and a public directory of every node's models and expertise.

Scale and resilience

  • Capacity grows as people add machines: a laptop, a gaming PC or a GPU server can join with one command.
  • The router is stateless and runs at Cloudflare's edge, close to your users.
  • If a provider fails, the request moves to another one, and an answer interrupted mid-stream continues on the next provider.
  • Nodes are checked continuously with test prompts, and traffic follows reputation.

Today one operator, the project's founders, runs the router. How it fits together

Inclusion

  • Anyone can supply intelligence: run a node and you get free network chat, 20,000 tokens a day plus every token your node serves.
  • Nodes earn PAI reward points for verified work (an off-chain unit with no market value today).
  • Open models at open-model prices put capable AI within reach of small teams, students and regions that frontier prices shut out.
  • Sign in with email, Google, Apple, GitHub or a wallet.

Transparency

  • Every response says which model and provider answered (x-decentralise-actual-model) and carries a receipt.
  • The live map shows every node, its models and its traffic by city.
  • Routing decisions can be explained: DSI Synapse shows each candidate's score and why it won.

Smarter than one model

  • Specialist nodes (for example law or accounting) declare their expertise, and questions in their field go to them.
  • With DSI Synapse on your device, a hard question can escalate to a stronger model, or get a second opinion, only when the first answer looks uncertain.
