How to read this. Locations are city-level: they come from Cloudflare's geolocation of each node's IP, rounded to about 10 km. Operators can opt out, and those nodes count only as "location hidden". Node names, addresses and operators are never shown. Requests and tokens are what nodes served through the router in the last 60 minutes; requests per minute uses the last complete minute. Projected PAI is today's provider reward pool (70% of the daily emission) shared by each city's portion of today's verified work so far. It is final only when the day's epoch is settled. PAI is currently an off-chain ledger, and no token has been issued. Data: /api/network/map (public JSON) · source on GitHub.
